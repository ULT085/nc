# 睡前復盤 2026-11-22：另一棵樹的子樹

嗨，晚安。歡迎收聽今天的睡前程式復盤。今天只有一題，Subtree of Another Tree，判斷一棵樹是不是另一棵樹的子樹。題目不多，剛好讓我們慢慢把它想透，順便跟前幾天寫過的題目串起來。放輕鬆，我們開始。

## 題目與整體思路

題目是：給你兩棵二元樹，root 和 subRoot，問 root 裡面有沒有某個節點，從那個節點往下長出來的整棵樹，跟 subRoot 一模一樣。注意，是「整棵」都要一樣，一路到葉子為止，不能只是上半部長得像。

你有沒有覺得這題很眼熟？前天我們才複習過 Same Binary Tree，判斷兩棵樹是否相同。而這一題，其實就是把 Same Binary Tree 當成工具，在 root 的每一個節點上都試一次。

所以你的解法分成兩層。外層的 isSubtree 負責「走遍 root 的每個節點」，內層的 isSameTree 負責「從這個節點開始，跟 subRoot 比對是不是完全相同」。只要有任何一個節點比對成功，答案就是 true。

## 內層：isSameTree

先看內層。你的 isSameTree 跟前天那題幾乎一樣：兩個都空，回傳 true；只有一個空，回傳 false；兩個都在，就要求值相同、左子樹相同、右子樹相同。

這裡有一個讓我很開心的細節：前天的集數提到，可以把「值相不相同」放在最前面，利用 and 的短路，值不一樣就馬上結束，不用先遞迴完整棵左子樹。而你今天的寫法，正好就是先比 a 的值等於 b 的值，再比左右。這個小優化在這題特別重要，因為 isSameTree 會在 root 的每個節點上被呼叫一次，大部分的節點第一眼值就不同，能早一步結束，整體就省下很多時間。

## 外層：兩個版本的差異

再來看外層，你寫了兩個版本，差別在開頭的邊界判斷。

第一個版本，開頭是：如果 root 和 subRoot 都是空的，回傳 true；如果其中一個是空的，回傳 false。接著回傳「從這裡開始相同」，或者「左子樹裡有」，或者「右子樹裡有」。

第二個版本，你把開頭改成：如果 subRoot 是空的，回傳 true；如果 root 是空的，回傳 false。然後先單獨判斷 isSameTree，成功就直接回傳 true，否則再往左右子樹找。

這兩個版本在題目的限制下結果都會通過，因為題目保證 subRoot 不是空的。但第二個版本在語意上更正確。想一想：空樹算不算任何一棵樹的子樹？算，因為每個葉子底下都掛著空指標。第一個版本中，如果 root 不是空的、但 subRoot 是空的，會落到「其中一個是空」那一行，回傳 false，這在數學上是錯的。第二版先問 subRoot 是不是空的，就把這個情況處理對了。

另外，第一版的判斷其實有點多餘：在外層遞迴的過程中，subRoot 永遠不會變，所以「兩個都空」的情況，只有在一開始 subRoot 就是空的時候才會發生。第二版把兩個角色分開來看：subRoot 是不會變的目標，root 是正在被走訪的樹，邏輯更清楚。這就是一次很好的重構：不是為了變快，而是讓每一行程式碼的意圖更明確。

## 複雜度與進階做法

時間複雜度方面，假設 root 有 m 個節點，subRoot 有 n 個節點。最壞情況下，root 的每個節點都要做一次比對，每次比對最多走 n 個節點，所以是 m 乘以 n。空間是遞迴的深度，也就是兩棵樹的高度。

面試時如果被問到能不能更快，有兩個常見的方向。第一個是序列化：把兩棵樹各自用前序走訪轉成字串，空節點也要寫進去，例如用井字號表示，而且每個值的前後要加上分隔符號，避免十二和二這種數字被誤判成相符。然後問題就變成「一個字串是不是另一個字串的子字串」，用 KMP 演算法就能在 m 加 n 的時間內完成。第二個方向是樹的雜湊：替每棵子樹算一個雜湊值，比對雜湊就好。這兩個做法知道概念就很加分。

## 今晚的重點回顧

好，最後我們把今天的重點收一收。

一句話：Subtree 就是在 root 的每個節點上，呼叫一次 Same Tree。

外層負責走訪，內層負責比對。邊界要分清楚：subRoot 是空的，永遠是 true；root 走到空了還沒找到，就是 false。

內層的 Same Tree，先比值再比左右，能早一步結束就早一步結束。

複雜度是 m 乘 n；想更快，就用序列化加 KMP，記得空節點和分隔符號都要寫進去。
